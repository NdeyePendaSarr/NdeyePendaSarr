## 📌 Projets

### 🏠 [Agence Immobilière — Real Estate Management](https://github.com/NdeyePendaSarr/real-estate-management)

Application de gestion immobilière **full-stack en PHP**, basée sur une architecture **MVC maison**, avec **PDO et MySQL**.

Projet initialement réalisé en Licence, puis **entièrement repris et modernisé en 2026** afin d'améliorer son architecture, sa sécurité et son expérience utilisateur.

Principaux éléments travaillés :

- architecture MVC ;
- authentification et contrôle d'accès par rôle ;
- protection contre les attaques **CSRF et XSS** ;
- requêtes préparées avec PDO ;
- validation des données côté serveur ;
- gestion sécurisée des uploads ;
- gestion des biens immobiliers ;
- gestion des réservations ;
- réservation transactionnelle pour éviter les conflits de dates ;
- interface responsive.

`PHP` · `MVC` · `PDO` · `MySQL` · `Sécurité`

### ⏳ [FocusDay](https://github.com/NdeyePendaSarr/focus-day)

Application de productivité conçue comme un **coach temporel**, plutôt qu'une simple todo-list.

FocusDay permet de :

- planifier des objectifs par créneaux horaires ;
- définir le "pourquoi" de chaque objectif ;
- suivre l'avancement de la journée avec une timeline ;
- gérer plusieurs statuts : à faire, en cours, terminé, manqué ;
- recevoir des rappels via l'API Notification du navigateur ;
- faire un débrief en fin de journée ;
- consulter l'historique avec recherche et filtres ;
- utiliser un thème clair ou sombre ;
- conserver les données localement avec `localStorage`.

Le projet possède également une couche métier dédiée à la gestion du temps et des tests automatisés avec Vitest.

`Next.js` · `TypeScript` · `Tailwind CSS` · `Vitest` · `localStorage`

🔗 [Démo en ligne](https://focus-day-nps.vercel.app/)
